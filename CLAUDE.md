# Maakit

**Read [`AGENTS.md`](AGENTS.md) in full before changing anything.** It is the
single rulebook for this repository, shared with every other tool that works
on this code. Everything — the business model, the money rule, the design
rules, the file map, the colours, and how to work without erasing someone
else's work — lives there.

Two things from it that are easy to get wrong, repeated here so they are not
missed:

1. **Pull before you push.** Another AI works on this repo. Run
   `git pull --rebase origin main` before you start and again before you push.
   Never copy a whole working folder over the repo without pulling first — it
   silently reverts the other side's work.

2. **Check what you displaced, not only what you added.** If you change where
   a form posts or replace a page, find out what the old one was doing that
   the new one is not.

The owner, Ankit, is not an engineer. Talk to him in Hinglish, simple words,
one step at a time.
