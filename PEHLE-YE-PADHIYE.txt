--------------------------------------------------------
KADAM 0 — PEHLE BACKUP (ye mat chhodiye)
--------------------------------------------------------
1. cPanel -> phpMyAdmin
2. baayen taraf apna database "maakit.in" dabaiye
   (DHYAN: wahi jisme aapka purana data hai)
3. upar "Export" -> "Go"
4. .sql file download hogi — computer me sambhal kar rakhiye


--------------------------------------------------------
KADAM 1 — config.php bhariye
--------------------------------------------------------
Zip me "config.php" hai. Notepad me kholkar ye 3 line badliye:

  define('DB_NAME', 'yahan_database_ka_naam');
  define('DB_USER', 'yahan_user_ka_naam');
  define('DB_PASS', 'yahan_password');

Jaanne ka tarika: cPanel -> File Manager -> public_html ->
purani config.php -> View -> wahi 3 cheezein utar lijiye.

Password mujhe kabhi mat bhejiye.


--------------------------------------------------------
KADAM 2 — file upload kijiye
--------------------------------------------------------
1. cPanel -> File Manager -> public_html
2. "Upload" -> maakit-system.zip chuniye
3. wapas aakar zip par right-click -> Extract
4. "Replace all" / "Overwrite" dabaiye


--------------------------------------------------------
KADAM 3 — uploads folder ko likhne layak banaiye
--------------------------------------------------------
(Ab customer parchi ki photo bhej sakta hai aur delivery
 boy bill ki photo lagata hai — isliye ye zaroori hai)

File Manager -> public_html -> "uploads" folder par
right-click -> "Change Permissions" -> 755 -> Save.


--------------------------------------------------------
KADAM 4 — database me do SQL chalaiye
--------------------------------------------------------
phpMyAdmin -> apna database -> "SQL" tab

Pehle:  install-salon.sql   poora paste karke "Go"
Phir:   install-app.sql     poora paste karke "Go"

(install.sql sirf khali database ke liye hai. Purane par
 zaroorat nahi — galti se chal bhi gaya to nuksan nahi.)

Beech me kuchh baar "1" dikhe to sahi hai, ghabraiye mat.


--------------------------------------------------------
KADAM 5 — phone me kholkar dekh lijiye
--------------------------------------------------------
maakit.in kholiye. Ye dikhna chahiye:

  [OK] sabse upar gaon ke naam chalti patti
  [OK] laal patti me "हिंदी/English" aur "लॉगिन" ka button
  [OK] 2 badi tiles: राशन  aur  खाना
  [OK] "What's on" me 3 offer card
  [OK] uske neeche 11 chhoti tiles (दवाई, गाड़ी, लॉन, टेंट…)
  [OK] neeche 5 button: Home, Order, Book, My orders, Services
  [OK] Order page par saaman ke chitr, "जोड़िए" -> [-] 1 [+]
  [OK] Chrome puchhega "Maakit ko home screen par rakhein?"

Agar saaman ki list khali dikhe -> KADAM 4 ka
install-app.sql dobara chalaiye.

KADAM 6 — password badliye (bahut zaroori)
--------------------------------------------------------
1. maakit.in/login.php  ->  admin / maakit123
