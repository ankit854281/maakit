# SNMSIS Board Prep for Android

Direct-install Android wrapper for https://maakit.in/school/board.php — Class 10 board exam practice
(owner, 13 Nov 2026: "class 10th ke liye students app banaiye … board ki taiyari").
Copy of the Data Entry wrapper (same trusted-origin rules); NCERT / CBSE links open in the phone's browser.
Login is the existing student login (admission number + PIN, first PIN 1234). No PIN or data is embedded.
Built by .github/workflows/board-apk.yml (Java 17, Gradle 8.9, SDK 34) with Android debug signing; published as a GitHub release.
