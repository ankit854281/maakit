# Teacher Profile Studio — Next.js client component

The deployed PHP school remains buildless. This folder is an explicitly requested portable React/Next.js deliverable, not a server migration. The integrated working school UI is `school/faculty.php` with its authenticated PHP API. Do not add a Node process to shared hosting merely to enable the Profile Studio.

Use `TeacherProfileStudio.tsx` inside a Next.js App Router page/client wrapper. Pass authenticated `initialState`, a memoized `api` adapter and the absolute `verificationBaseUrl` pointing to `/school/faculty-verify.php`. `php-adapter.ts` works on the same origin or through an authenticated server proxy; it does not enable wildcard CORS. Never pass a Principal token to a teacher browser. For a separate deployment implement the same API interface with verified server sessions and class/teacher authorization.

Required development dependencies: React 19.2, TypeScript 5.9, Tailwind 3.4.17, qrcode-generator 1.4.4 and React types. The client component needs no Next-specific imports, so it can be mounted in an existing Next app. React role checks are presentation only: all permissions, stale-version rejection, approval, credential verification and ID revocation are enforced by the PHP API. The plain PHP implementation also includes Principal branding settings, CL ledger entry, credential review, private peer appreciation and Secret Saathi reflection.

Tailwind configuration/components: `school/build/tailwind.config.js` and `school/build/app.input.css`. Add the TSX source to the consumer's `content` list and include `edu-*` classes from that input file. Import the generated CSS in the Next root layout. The existing school's compiled `school/app.css` is committed and needs no runtime build. Respect reduced motion and solid-background fallbacks.

The PostgreSQL `schema.prisma` uses Prisma 6.19 syntax, the explicitly pinned reference version. Validate/migrate in a PostgreSQL staging environment, not the current MySQL database. It models `faculty_profiles` and `teacher_credentials` with composite school/profile relations. Add tenant RLS and your identity/actor foreign keys in the actual learning-service migration. Encrypt optional contact/health/emergency fields with a server-side key-management design; no key is embedded in this component. Roles must not write approval snapshots or ID token hashes through generic CRUD. Service methods enforce valid CPD dates/hours, school scope, verified identity roles and approved revision consistency.

ID tokens must be high-entropy, revocable, expiring and stored hashed in the PostgreSQL service. A teacher edit leaves the old approved ID snapshot active until a new revision is approved; reapproval rotates the token. Sharing withdrawal takes effect immediately after save. Public directory serializers expose only approved professional fields, never contacts, health, emergency details, private notes or leave.

No signature is forged or auto-generated. Only an authorized uploaded signature may be passed via `signatureImageUrl`. The school affiliation identifier is not pre-asserted as CBSE 71204: Principal must verify and configure the correct value. The printed code is a staff identifier, not biometric data. CL metrics are from an explicit Principal ledger; old generic leaves are not silently classified as CL. No biometric feed is connected; no streak is fabricated. CPD shows verified hours toward a 50-hour session target, not an automatic CBSE compliance certification. Source: https://www.cbse.gov.in/cbsenew/documents/CPD_Guidelines2025_01042025.pdf

Profile onboarding is for existing Principal-provisioned teacher accounts. It never creates privileged login roles or rewrites allocations. Principal approval checks the existing grid for duplicate teachers in one bell and stale references; timetable editing/generation stays in Timetable. Camera dock opens the existing Smart Studio upload/checking workflow; SNAP-TO-CLASS photo-to-pedagogy remains a separate future implementation. Secret Saathi here is an account-private reflection journal, not AI therapy.
